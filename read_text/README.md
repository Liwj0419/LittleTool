# read_text

本工具在自己的 `config.json` 声明 `appName` 和 `tool.mode="background"`，由 Manager 自动发现。所有命令在本工具目录运行。

`--show` 复用已有实例；`--hidden` 按工具形态启动；`--reload` 重读运行中实例的配置；`--quit` 独立退出；`--selftest` 无界面检查后退出。两个启动脚本原样透传参数，运行始终使用自己的 `.venv`。

把屏幕上**任意一张图片里的文字**，当作真文本拖选出来。

截图贴在屏幕上、网页里嵌的图、播放器暂停的画面——按一下热键，鼠标下的那个窗口就被"锁"住，
鼠标移到文字上会变成竖线光标，像选网页文字一样拖选，**再按 Ctrl+C 复制**。

松手不会复制、也不会关窗，你可以反复调选区，满意了再复制。

## 用法

1. 双击 `read_text_start.bat`（第一次会自动建 `.venv` 装依赖），不创建托盘，程序在后台待命。
2. 把鼠标停在你想取字的**图片/窗口**上，按 `Alt+F1`。
   目标窗口立刻被锁住，顶部出现「正在截取文字中…」。
3. 识别完成后，鼠标靠近文字会变成竖线，按住左键拖选，再按 `Ctrl+C` 复制。
4. 复制完覆盖层自动收起；不想复制就按 `Esc`。

识别中和识别失败会显示状态提示。将 `overlay.showHint` 设为 `true` 可在选字时显示操作说明和选中字符数。

覆盖层显示时再按一次热键是取消。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| `Alt+F1` | 锁定鼠标下的窗口 / 收起覆盖层 |
| 拖选 | 只选中，不复制、不关窗 |
| `Ctrl+C` | 复制选中文字，然后收起 |
| `Esc` | 退出取字模式（不复制） |
| `Ctrl+A` | 全选这张图里的所有文字 |

都可以在 `config.json` 里改。`Esc` / `Ctrl+C` / `Ctrl+A` 都读配置，不是写死的。

## 原理

```
热键 → 取鼠标下窗口的矩形（物理像素）
     → 截这块屏幕，交给系统 OCR，拿到文字块的坐标
     → 在同一位置盖一个置顶窗口，铺上截图当背景，在文字块上绘制拖选高亮
     → 鼠标命中的是文字层，所以有竖线光标、能拖选；按 Ctrl+C 把选区拼起来写进剪贴板
```

几个关键点：

- **锁的是「鼠标指针下的那个窗口」，不是焦点窗口**，也不是整块屏幕。
  鼠标停在哪个窗口上就锁哪个，跟当前谁有输入焦点无关。
  例外是那个窗口本身铺满了屏幕（最大化、无边框全屏）：这时锁定的矩形就等于整屏，
  识别也会变慢。顶部提示条里会写「正在识别这块 W×H 区域…」，看一眼就知道锁了多大。
- **窗口不透明也没关系**：覆盖层的背景就是目标区域的那张截图，所以你看不出上面多了一层；
  只有拖选时的高亮浮在图片上。代价是取字期间那张图必须是静止的。
- **覆盖层按截图坐标处理拖选**。英文、数字和 ASCII 符号可以逐字符选择，例如路径里的一段名称或单个下划线。
- **不安装第三方 OCR 库**。用的是 Windows 自带的 `Windows.Media.Ocr`（系统里有中文语言包就能用），
  通过一个常驻的 PowerShell 子进程调用，见 `assets/ocr_bridge.ps1`。
- 有英文 OCR 语言包时，识别到英文字母或数字会再用英文模型识别一次。位置吻合且补回了路径符号或字符的结果可替换原有英文文字块。
- 小图按 `ocr.upscale` 放大后再识别，让引擎看清较小的字。长边达到 1600 像素时跳过放大，以缩短识别时间。
  坐标会按实际缩放比折回原图。
- **英文单词会被 OCR 拆碎**（`PowerToys` → `P owe rToys`），复制时按字块间距决定要不要补空格，
  所以拼出来仍然是 `PowerToys` 而不是 `P owe rToys`。

## 已知限制

- Windows 专属：系统 OCR 来自 `Windows.Media.Ocr`，其他平台目前只会提示不支持。
- 锁定期间**不要移动或缩放**那张贴图，否则文字层会和图片错位（按 `Esc` 重锁即可）。
- 只处理静态画面。视频播放中、正在滚动的页面，坐标会立刻失效。
- 竖排文字、艺术字、极小的字号识别率有限。
- 英文块内的字符边界按字宽和截图上的字缝估算。字很小或笔画相连时，可以用左右方向键微调选区。

## 配置

`config.json` 支持 `//` 注释，改完执行 `./run.sh --reload`即可生效，不用重启。

| 项 | 说明 |
| --- | --- |
| `shortcuts.global` | 唤起热键 |
| `shortcuts.copy` / `.cancel` / `.all` | 复制 / 退出 / 全选，页面按配置实时匹配 |
| `overlay.selectionColor` | 拖选高亮色 |
| `overlay.showHint` | 是否显示拖选说明和选中字符数 |
| `ocr.upscale` | 识别前放大倍数，1–3 |
| `ocr.joinGap` | 字块间距超过「字宽 × 该值」才补空格 |
| `behavior.copyOnRelease` | 默认 `false`：选中后等你按 Ctrl+C。改成 `true` 就变回松手即复制 |
| `behavior.closeOnOutsideClick` | 默认 `false`：点空白不关窗。改成 `true` 才关 |

## 启动方式

```bash
./run.sh              # 后台常驻
./run.sh -c           # 带控制台，看日志和报错
./run.sh --selftest   # 自检：跑一遍「找窗口 → 截图 → 识别」，写 selftest.log
./run.sh --where      # 看一眼「现在按热键会锁哪个窗口」，不出界面
./run.sh --devtools   # 带开发者工具
```

`read_text_start.bat` 与 `run.sh` 行为一致，都认 `--hidden` / `--devtools` / `--selftest` / `--where`。

`--where` 的输出长这样，可以确认自己锁的到底是不是那张图：

```
窗口类名 : Chrome_WidgetWin_1
窗口标题 : WorkBuddy
原始矩形 : 1920x1160 @ (3840,240)
实际锁定 : 1920x1160 @ (3840,240)
整块桌面 : 5760x2160，锁定占 18%
```

日志在 `%APPDATA%\read_text\app.log`。
