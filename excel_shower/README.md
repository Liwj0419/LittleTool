# Excel 数据查看器

本工具在自己的 `config.json` 声明 `appName` 和 `tool.mode="resident"`，由 Manager 自动发现。所有命令在本工具目录运行。

`--show` 复用已有实例；`--hidden` 按工具形态启动；`--reload` 重读运行中实例的配置；`--quit` 独立退出；`--selftest` 无界面检查后退出。两个启动脚本原样透传参数，运行始终使用自己的 `.venv`。

一个只用来「看」表格的桌面小工具。打开快、界面干净、**绝不改动原文件**，
关掉窗口也不会退出，后台待命，可用热键或启动入口随时唤出。本工具不创建托盘。

界面用 HTML 渲染，装在 **WebView2（Chromium）** 里，跟浏览器同一套排版和滚动引擎，
所以**滚动是丝滑的**——不是 Tk 那种一格一格重画的卡顿。

## 怎么用

双击 **`excel_shower_start.bat`** 即可。第一次运行会自动建 `.venv`、装依赖，不用手敲命令。

- 把表格文件**拖到 `excel_shower_start.bat` 上**
- 命令行：`excel_shower_start.bat "C:\表格\示例.xlsx"`
- 命令行调试（能看到输出和报错）：`run.sh -c 表格.xlsx`

不管双击多少次，都只会有一个窗口：后启动的进程把文件交给已经在跑的那个，
然后自己退出。

## 界面说明

```
[历史 ▾] [选择文件] [打开文件]            文件名.xlsx
工作表 [ItemPage ▾]  列 [全部 ▾]              [◉ 全部表] [搜索…]
────────────────────────────────────────────────────────────
 #  │ INT_TYPE          │ INT_PAGE        │ STR_NAME │ ...
 2  │ ITEM_CLASS_...    │ BAG_PAGE_...    │ 材料      │
────────────────────────────────────────────────────────────
 43 行 × 7 列 · 读取 0.01s · 只读模式        已选 3 行 × 2 列 · Ctrl+C 复制
```

- 文件名显示在标题栏**正中间**（窗口标题也跟着变）
- `历史 ▾`：最近打开过的文件（清空时当前文件会保留）
- `选择文件`：在查看器里挑一个表格打开，默认停在**当前文件所在的文件夹**
- `打开文件`：用系统默认的 Excel / WPS 打开当前这个文件（想编辑时用）

| 操作 | 效果 |
| --- | --- |
| 在单元格上**单击 / 按住拖动** | 框选任意一块区域（像 Excel 那样）；搜索完直接点结果行也一样能框 |
| `Ctrl+C` | 把框选的区域复制成制表符分隔，直接粘到 Excel / 聊天框 |
| `Ctrl+A` | 全选整张表 |
| 点列标题 | 按该列排序（再点倒序，第三次取消） |
| `列` 下拉 | 勾选要显示哪些列（只显示字段名），可多选，**点完不关**；有「全部显示 / 全部隐藏」 |
| `全部表` 开关 | 开（默认）= 搜整个文件的所有工作表；关 = 只搜当前工作表 |
| 搜索框输入 | 模糊过滤，实时出结果 |
| 双击单元格 | 弹出完整内容（长文本看全用） |
| 搜索结果的 `前往` 列 | 每行开头一个 `→`：清空搜索、切到那一行所在的工作表，并滚动过去；落地的那一行会留下**常驻黄色底色**（左侧一条橙色竖线），直到你重新搜索 / 换表 / 换文件才消失 |
| 工作表下拉 | 多 Sheet 文件切换表；面板顶上带搜索框，边打边模糊过滤（支持跳字，`销明` 也能命中 `销售明细`）；`↑` `↓` 换行、`Enter` 打开选中的那个（列表到头会绕回去） |
| 滚轮 | 跟浏览器一样顺滑；`Shift + 滚轮` 横向滚动 |

只要在搜索，表格前面就会多出「前往」一列（按 `Esc` 清掉搜索词就消失）。
全表搜索时箭头后面还跟着工作表名，标明每条结果来自哪个 Sheet；只搜当前表、
或者文件本来就只有一个工作表（CSV 更是）时，就只有箭头。

全表搜索会把列结构不同的几张表混在一屏里，所以列布局**按列名统一**：
表头 = 各工作表列名的并集（当前工作表在前，其它表独有的列按表顺序追加），
每一行按列名映射到自己的列，别的表没有这个字段就留空。同一个表头下面永远是
同一个字段，不会出现「值跑到别的列底下」的错位；状态栏会注明「合并显示 N 列」。

快捷键全部来自 `config.json`（默认 `Ctrl+O` 打开、`Ctrl+F` 搜索、`Ctrl+A` 全选、
`Ctrl+C` 复制、`F5` 重新读取、`Esc` 收起）。

窗口不管是启动、按热键叫出来、从启动入口打开，还是被别的程序投文件，都会**跳到最前并接管键盘焦点**，
落地时焦点就在表格上——`Ctrl+F`、方向键、`Ctrl+C` 直接能用，不用先点一下表格。

`Esc` 默认一步收起：**不管当前有没有选区、搜索词、弹窗，按一下就收起窗口**。
（想让它一层一层退——先撤选区、再清搜索、最后才收起，把 `config.json` 里的
`"esc"` 改成 `"layered"`。）

## 关掉之后去哪了

点窗口的 × **不会退出程序**，只是隐藏窗口并在后台待命，再打开是秒开的。

重新叫出来的方式（任选其一）：

- 按 **`Ctrl+Alt+E`**（全局热键，任何程序在前台都有效，可在 `config.json` 里改）
- 在 Manager 中点本工具的「打开窗口」
- 再双击一次 `excel_shower_start.bat`

真正退出：`./run.sh --quit`。

## 配置：`config.json`

程序**只读不写**这个文件（所以注释永远不会丢），改完执行 `./run.sh --reload`即可生效，
不用重启。

```jsonc
{
  "window": { "width": 1100, "height": 680, "minWidth": 820, "minHeight": 520 },
  "shortcuts": {
    "global":    "Ctrl+Alt+E",   // 全局唤出
    "hide":      "Esc",          // 收起窗口
    "open":      "Ctrl+O",
    "search":    "Ctrl+F",
    "reload":    "F5",
    "selectAll": "Ctrl+A",
    "copy":      "Ctrl+C"
  },
  "esc": "close",                // close = 直接收起；layered = 一层层退
  "port": 47653,                 // 单实例通信端口（被占用会自动往后找）
  "maxRows": 200000,             // 单表最多读多少行
  "pageRows": 2000,              // 每次往页面送多少行
  "maxRecent": 8                 // 历史菜单最多记几条
}
```

快捷键支持 `Ctrl` / `Alt` / `Shift` / `Win` 组合，键名可以是字母、数字、`Esc`、
`Enter`、`F1`-`F12`、`Space`、`Tab`、`Up` / `Down` / `Left` / `Right`、`Home` / `End`、
`PageUp` / `PageDown` 等；留空或删掉整行表示不用这个快捷键。

最近打开的文件、窗口位置、实际使用的端口记在
`%LOCALAPPDATA%\ExcelShower\state.json`，不写进 `config.json`。

## 命令行

| 命令 | 作用 |
| --- | --- |
| `excel_shower_start.bat` | 双击启动（无黑框，自动建环境） |
| `run.sh` | 同样行为，命令行版 |
| `run.sh -c` | 用 `python.exe` 跑，能看到控制台输出和报错 |
| `run.sh --hidden` | 静默启动，后台待命，不创建托盘 |
| `run.sh --devtools` | 带开发者工具 |
| `run.sh --selftest` | 自检：写 `selftest.log`（无界面） |
| `python app.py --dump 表格.xlsx` | 不开界面，只打印解析结果 |

`excel_shower_start.bat` 和 `run.sh` 行为一致，都认 `--hidden` / `--devtools` / `--selftest`。

## 和 excel_quick_search 联动

`excel_quick_search` 里搜索到的表格，**默认用这个查看器打开**
（它内部调用了同目录下的 `excel_shower_link.py`）：

- 查看器开着 → 直接把文件投过去并弹到前台，耗时 1 毫秒级
- 查看器没开 → 自动帮你启动一个
- 找不到这个文件夹 → 自动退回原来的「用系统默认程序打开」

所以在 quick_search 里回车/双击，看到的就是这个只读窗口；
想改用 Excel 编辑，点窗口上的「打开文件」就行。

## 支持格式

`.xlsx` `.xlsm` `.csv` `.tsv` `.txt`

不支持老的 `.xls`（二进制格式），需要先用 Excel/WPS 另存为 `.xlsx`。

## 几点说明

- **解析零依赖**：读 xlsx 用的是 Python 标准库（`zipfile` 直接读 OOXML），
  不需要 `openpyxl`。
- **只读**：程序只读取文件内容，不会写回、不会锁定文件，
  可以一边开着看一边在 Excel 里改。
- **虚拟滚动**：界面里永远只有一屏的 DOM，滚到哪画到哪，
  20 万行的表也不会因为"行数多"而变慢。
- **列宽**：`max(这一列最长内容, 表头文字) 的字符数 + 一点缓冲`，
  超过上限（约 40 个字符）就截断到上限，不会被 Excel 里乱七八糟的列宽带偏。
- **日期**：日期格式的单元格按 `2026-01-15` 显示，不会变成一串数字。
- **清空历史**：最近文件菜单里的「清空列表」只清别人，**当前正在看的这个文件会保留**。
- **窗口位置**：多显示器 / 高 DPI 下会记住上次的位置，且保证不会跑到屏幕外面去。
- **不打包**：没有 exe，直接跑源码；解释器用项目里的 `.venv`。

## 文件

| 文件 | 作用 |
| --- | --- |
| `app.py` | 入口：解析参数、单实例判断、交给 `core.App` |
| `config.json` | 配置（窗口、快捷键、端口、行数上限） |
| `excelshower/sheet.py` | 解析层：xlsx / csv 只读解析（纯标准库） |
| `excelshower/model.py` | 视图状态：搜索、排序、列显示、分页取行 |
| `excelshower/server.py` | 本地 HTTP 服务：页面 + 数据接口 |
| `excelshower/window.py` | pywebview 窗口：显示 / 隐藏 / 标题 / 文件选择框 |
| `excelshower/core.py` | 把窗口、热键、服务、单实例串起来 |
| `excelshower/hotkey.py` | pynput 全局热键 |
| `excelshower/ipc.py` | 单实例通信（把文件投给已经开着的窗口） |
| `excelshower/native.py` | Win32：摆窗口、抢前台、改标题（ctypes） |
| `excelshower/config.py` | 读 `config.json`（支持注释）、日志、状态文件 |
| `excelshower/selftest.py` | `--selftest` 自检 |
| `assets/index.html` | 界面：工具栏 + 虚拟滚动表格（单文件，无框架） |
| `assets/icon.ico` | 程序窗口图标 |
| `excel_shower_link.py` | 给外部程序投递文件的公开接口；使用本工具自己的解释器 |
| `excel_shower_start.bat` / `run.sh` | 双击启动 / 命令行启动 |

需要 Python 3.10+；窗口/热键的依赖见 `requirements.txt`
（`pywebview` / `pynput`）。

## 调试

- 运行日志：`%LOCALAPPDATA%\ExcelShower\app.log`（页面里的 JS 报错也写这里）。
- `python app.py --dump 表格.xlsx` 不开界面，只打印解析结果。
- `run.sh --selftest` 无界面检查配置、独立环境、中文 CSV 读取与搜索，结果在 `selftest.log`；
  不启动窗口或热键，不修改用户历史。快捷键需要在实际窗口中单独验收。
- 快捷键不灵时先看两件事：窗口得在前台（后台窗口收不到按键），
  以及 `config.json` 里的写法——`Ctrl+F` 的修饰键、字母大小写都按字面解析。
