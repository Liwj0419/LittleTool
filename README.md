# LittleTool Windows 小工具

1. 把整个文件夹解压到本地，双击里面的 `manager_start.bat`。
2. 第一次使用需要联网。缺少 Python 或 WebView2 时，按弹窗提示安装。
3. 在工具箱管理器打开想用的「运行」开关。等安装完成后，按下表里的快捷键。

| 工具 | 快捷键 | 怎么用 |
| --- | --- | --- |
| 自定义指令 | `Ctrl+Alt+,`（逗号） | 输入指令名，按回车打开。可以先试试「用户文件夹」。按 `Ctrl+O` 打开配置，在 `commands` 里添加自己的文件或文件夹。 |
| 搜索EXCEL | `Ctrl+Alt+.`（句号） | 填好表格目录后，输入文件名关键词，双击结果打开。 |
| 显示EXCEL | `Ctrl+Alt+E` | 按 `Ctrl+O` 选表格，按 `Ctrl+F` 搜索内容。支持 `.xlsx`、`.xlsm` 和 `.csv` 等格式，可以查看和复制。 |
| 屏幕取字 | `Alt+F1` | 把鼠标放到要取字的窗口上，再按快捷键。识别完成后拖选文字，按 `Ctrl+C` 复制，按 `Esc` 取消。 |
| 翻译 | `Ctrl+Alt+2` | 输入或粘贴文字，自动中英互译。需要联网，输入的文字会发送给 MyMemory。 |

### 第一次用「搜索EXCEL」

点管理器中该工具旁的文件夹图标，用记事本打开 `config.json`。在 `sources` 里找到 `"path": ""`，填入自己的表格目录，例如 `"path": "C:/表格"`。保存后，把这项的「运行」关掉再打开。

### 收起和退出

按 `Esc` 可以收起工具窗口。要退出工具，在管理器关掉对应的「运行」开关。用 `Ctrl+Alt+0` 唤出管理器，右键任务栏通知区的工具箱图标可退出管理器。

只想用其中一个工具时，可以进它的文件夹，双击该工具的 `*_start.bat`。各工具目录里的 README 有更多说明。
