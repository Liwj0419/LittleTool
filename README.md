# LittleTool Windows 小工具

## 开始使用

1. 把整个文件夹放到本地，双击根目录的 `manager_start.bat`。
2. 第一次使用保持联网。如果提示缺少 Python 或 WebView2，按提示安装。
3. 在工具箱管理器打开想用的「运行」开关，等安装完成后再使用该工具。按 `Ctrl+Alt+0` 可以唤出管理器。

在管理器点工具旁的文件夹图标，可以用记事本打开该工具的 `config.json`。要换唤起键，改开头 `shortcuts` 里的 `global`，保存后重启工具。填写路径时，可以从资源管理器地址栏复制文件夹路径，把反斜杠 `\` 换成 `/`，例如 `C:/资料/表格`。填单个文件时再加上文件名。

## 自定义指令

把常用文件夹和文件存成有名字的指令。按 `Ctrl+Alt+1` 唤出窗口，输入名称后按回车。可以先试试自带的「用户文件夹」。

### 添加指令

1. 用记事本打开 `custom_instruct/config.json`。
2. 参考下面的示例修改 `commands` 整段。`name` 是你要搜索的名字，`command` 填 `open`，`path` 填要打开的文件夹或文件。

   ```jsonc
   "commands": [
     { "name": "报表文件夹", "command": "open", "path": "C:/示例/报表" },
     { "name": "月报", "command": "open", "path": "C:/示例/报表/月报.xlsx" }
   ],
   ```

3. 保存配置，重新唤出自定义指令就能搜索新加的名称。

## 搜索EXCEL

按文件名在指定文件夹及其子文件夹中查找表格。适合记得文件名的一部分，想快速找到文件位置时使用。

### 设置搜索目录

1. 用记事本打开 `excel_quick_search/config.json`。
2. 参考下面的示例修改 `sources` 整段。`path` 填自己的表格目录或单个表格文件，`name` 是显示名称。多个目录使用不同的 `key` 数字。

   ```jsonc
   "sources": [
     { "key": "1", "name": "工作报表", "path": "C:/示例/报表" },
     { "key": "2", "name": "统计台账", "path": "C:/示例/台账" }
   ],
   ```

3. 保存后，在管理器把「搜索EXCEL」的「运行」开关关掉再打开。

按 `Ctrl+Alt+2` 唤出。只填了一个目录时会直接扫描，填了多个时可以按对应的数字选择。输入文件名关键词，双击结果或按回车，用系统默认软件打开。按 `Ctrl+Enter` 可以在资源管理器定位选中的文件，按 `F5` 重新扫描当前目录。

## 显示EXCEL

以只读方式查看表格，可以切换工作表、搜索内容和复制单元格。支持 `.xlsx`、`.xlsm`、`.csv`、`.tsv` 和 `.txt`。

按 `Ctrl+Alt+3` 唤出，按 `Ctrl+O` 选择文件。用 `Ctrl+F` 跳到搜索框。选中单元格后按 `Ctrl+C`，可将内容粘贴到 Excel 或其他应用。

## 屏幕取字

复制截图、网页图片或其他窗口中的文字。先把鼠标移到要取字的窗口上，再按 `Alt+F1`。识别完成后拖选文字，按 `Ctrl+C` 复制。按 `Ctrl+A` 可全选，按 `Esc` 取消。

## 翻译

按 `Ctrl+Alt+4` 唤出，输入或粘贴文字，工具会自动识别中英文并翻译。按 `Ctrl+Enter` 立即翻译，按 `Ctrl+Shift+C` 复制译文。翻译需要联网，输入的文字会发送给 MyMemory。

## 收起和退出

按 `Esc` 收起工具窗口。要停止工具，在管理器关掉对应的「运行」开关。要退出管理器，右键任务栏通知区的工具箱图标，选择「退出」。

只想用一个工具时，也可以在它的文件夹里双击对应的 `*_start.bat`。各工具目录下的 README 有单独使用和退出的说明。
